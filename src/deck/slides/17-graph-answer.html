17 Why graphs

Store the edges between those facts and both questions answer themselves

A graph adds two things a vector index has no way to hold: a typed edge saying which fact relates to which, and a supersedes edge saying which fact replaced which. Move the clock and watch the second one work.

Four checks the graph runs before anything is exposed
Lifecycle Is this still live, or has a supersedes edge retired it? A correction updates memory here instead of appending a second, contradictory fact beside the first.
Scope Was it recorded for the context being asked about, or borrowed from a different engagement, region, or client?
Authorization May this particular asker see it? The check reads the same Unity Catalog permissions as every other asset.
Source grounding Does a citable source actually state it? Vector search is treated as a candidate generator, never as the authority.
Both failures from the previous slide, with the edges in place
“Who leads the parent company of Beta Logistics?” Beta Logistics —PARENT→ Acme Holdings —LED_BY→ Maya Okonjo The two documents never had to be matched to each other. The edge between them was extracted once, at write time.
“Who leads Acme Holdings?” Ray Duval —SUPERSEDED_BY→ Maya Okonjo The 2018 record is not deleted and not repeated. It is retired, still auditable, and still the right answer to a question asked about 2018.
