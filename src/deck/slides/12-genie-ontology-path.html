12 Client need

“Make Genie answer better over the data we already have”

Genie Ontology generates the semantic map from what already exists. Curated Unity Catalog semantics are how you steer it — a product surface, not a build.

What curating this path looks like

Cumulative, not alternatives — every step keeps the ones before it, and each one adds to how much meaning Genie has to reason with.
