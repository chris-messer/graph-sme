06 Taxonomy

A taxonomy is a classification tree — technically a graph, and a table still answers it

One parent per node, root down to the lowest category — the products themselves hang below the tree. It is the product hierarchy this section keeps coming back to, and it is the layer where the most avoidable pain lives.

What this section actually decidesNot whether to run a graph engine — nothing on this canvas needs one. It is which encoding you store the tree in, because that choice is what decides whether an agent writes correct SQL over it. Six encodings and where we land come next.
