20 Recommendation

Start with agent traversal; each step up needs a failed benchmark query

Three steps, each a bigger commitment than the one before it. Nothing moves up on preference — a query has to fail first, and most never do.

Start here

Agent traversal over the stored node and edge tables

Hand Genie agents the nodes and the edges and let the agent do the walk — query, read what came back, follow the next edge. Nothing new to stand up, nothing new to govern.

Earned by default. This is where every graph question starts.

Next step

Lakebase-native graph retrieval

Text → SPARQL → SQL, or a Postgres graph extension running over Lakebase. Real graph semantics and deterministic answers, still on the same edges and still nothing to buy.

Earned by a benchmark query the walk gets wrong, or too slowly.

Last resort

A partner graph database such as Neo4j

The biggest commitment on the page: a second engine to stand up, govern and keep in sync. Delta stays the system of record and the edges sync outward.

Earned only when that same query still fails on Lakebase.
