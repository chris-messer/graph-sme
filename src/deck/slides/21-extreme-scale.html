Across this rail the algorithms do not change. What changes is which component is still allowed to run when the question arrives.

What is allowed to run when the question arrives At query time Precomputed in batch to Delta schematic, not a measurement
Connectivity is not coordination Naive connected components percolates, and a third of the graph can collapse into one component. Require corroboration — two shared signals, or one rare one — then split residual chains with community detection and rank clusters by cohesion.
The scoping cut is a parameter, not a rewrite Scoping to the region or bloc the questions actually live in is what makes this size tractable, and keeping the cut in configuration means widening it later is a parameter change.
